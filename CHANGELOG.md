# Changelog

## 0.2.0

- Native Rust/Ratatui application with a minimal clock, three themes, and quiet mode.
- Silent focus overtime and configurable break alerts.
- Live focus totals, a scrollable week calendar, and exact daily session times.
- Atomic timer checkpoints, paused recovery, and sleep detection.
- Read-only weekly reports and CSV exports.
- Existing session databases and settings remain compatible.
- Installable `pomo-tui` Cargo package exposing the `pomo` command.
- Release archives and checksum-verified installers for macOS, Linux, and Windows.
- Removed the Textual application and Python packaging layer.
